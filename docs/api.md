# 股息观察 API · A 股关注列表

支持东方财富搜索可确认的沪、深、北交易所 A 股，包括科创板、创业板。东方财富提供公司搜索和市场身份，腾讯提供行情与行情名称，东方财富提供分红记录。巨潮和 D1 尚未接入。没有人工维护的公司白名单；支持范围不代表每家公司都有行情或分红数据。

## 接口

| 方法与路径                             | 参数                                             | 返回数据                                   |
| -------------------------------------- | ------------------------------------------------ | ------------------------------------------ |
| GET `/api/health`                      | 无                                               | 保留既有健康响应                           |
| GET `/api/companies`                   | 必填 `q`，去空白后 1–50 字符                     | 最多 10 个 A 股搜索结果：名称、代码、市场  |
| GET `/api/quotes`                      | 必填 `codes`，逗号分隔、去重后最多 50 个六位代码 | 每只股票的价格、行情时间或错误             |
| GET `/api/companies/:code/dividends`   | 六位代码                                         | 东方财富原始含义的记录、财年汇总、参考财年 |
| GET `/api/companies/:code/allocations` | 六位代码                                         | 同财年归母净利润与已实施现金分红总额       |

除健康接口外，成功响应采用 `{ data, meta }`，整体错误采用 `{ error: { code, message } }`。精确类型见 `shared/api.ts`。

`meta` 只描述来源、抓取开始时间 `fetchedAt`、缓存 `hit/miss`、校验问题 `issues`，不描述分红进度。接口响应给浏览器使用 `Cache-Control: no-store`；数据源缓存独立存在于 Worker Cache。

- 400：参数格式错误、重复参数或数量超限。
- 404：不支持的股票或不存在的接口。
- 503：来源访问失败、响应不可用，或请求的行情全部不可用。
- 500：应用内部错误，不向客户端暴露堆栈。

### 公司与行情

公司搜索使用 `searchapi.eastmoney.com/api/suggest/get`，请求 `type=14`、`count=30`，过滤后最多返回 10 条。空输入、重复参数返回 400；输入更具体的名称或代码可缩小结果。来源明确的空结果返回 `data=[]`，接口失败返回 503，二者不混淆。

`Company` 为 `{ code, name, market }`，`market` 为 `SH | SZ | BJ`。仅按来源 `SecurityType` 与 `JYS` 的明确组合识别：

| 来源类型 / 交易场所 | 市场               |
| ------------------- | ------------------ |
| `1 / 2`、`25 / 23`  | SH（沪 A、科创板） |
| `2 / 6`、`2 / 80`   | SZ（深 A、创业板） |
| `27 / 81`           | BJ（京 A）         |

指数、基金、债券、港美股等不进入结果。未知的 A 股市场组合或身份字段错误返回校验问题，不根据证券名称、文字描述或代码前缀猜测。相同代码的冲突身份被省略。来源代码表在 `worker/providers/companies.ts`，它不是公司名单。

行情与分红请求先按完整六位代码精确查询身份，再构造市场标识；例如 `000001` 必须匹配深市 A 股而非上证指数。身份查询失败返回不可用，搜索中确实没有符合范围的精确匹配才判为不支持。首页旧有的六位自选代码无需迁移。

行情仅批量请求当前需要的公司，解析同时校验市场标识与代码；名称直接采用行情源返回值，不与搜索名称强制一致。行情 `data` 为 `{ code, quote, error }[]`。`quote.price` 是人民币每股十进制字符串；价格或时间单字段异常时保留其他有效字段，并在 `quote.issues` 中说明。不存在的记录或不支持的代码返回单项错误，其他成功项继续返回。行情时间带 `+08:00` 时区，与获取时间分别保存，休市时不宣称重新抓取就是价格更新。

### 分红记录

分红响应包含 `company: { code, name, market }`，来自本次已校验的公司身份；即使分红记录为空也返回。详情页无需依赖行情接口获取名称和交易所。

分红按完整 `SECUCODE`（如 `600900.SH`、`000001.SZ`、`920002.BJ`）过滤，并同时核对每条记录的 `SECURITY_CODE` 与 `SECUCODE`。不拼接固定 `.SH`，也不自行补接更名前代码的历史。

记录直接保留东方财富字段含义：

| API 字段                            | 来源或转换                     |
| ----------------------------------- | ------------------------------ |
| `sourceName`                        | SECURITY_NAME_ABBR             |
| `reportDate` / `fiscalYear`         | REPORT_DATE 及其年份           |
| `progress`                          | ASSIGN_PROGRESS 原始文本       |
| `cashPerTenShares` / `cashPerShare` | PRETAX_BONUS_RMB 及精确除以 10 |
| `planNoticeDate`                    | PLAN_NOTICE_DATE               |
| `latestNoticeDate`                  | NOTICE_DATE                    |
| `recordDate`                        | EQUITY_RECORD_DATE             |
| `exDate`                            | EX_DIVIDEND_DATE               |
| `bonusRatio` / `transferRatio`      | BONUS_RATIO / IT_RATIO         |
| `description`                       | IMPL_PLAN_PROFILE              |
| `payDate` / `announcementUrl`       | 当前来源未提供，保持 null      |

`raw` 保留来源返回的原始字段。原始字段可能是数字，标准化金额字段使用十进制字符串；未知原始进度保持原文，不转成自造的状态枚举。不根据描述文字识别取消、送转或特别分红，不根据报告期补造“末期分红”类型，也不根据除息日生成已派发或已到账状态。

`recordId` 为对排序后的原始字段计算的指纹，仅用于完全重复去重和当前响应内定位；不是跨版本稳定业务事件 ID。完全相同记录去重，不同记录不擅自覆盖。同一报告期的已实施记录中，只有登记日和除息日均明确且彼此不同的记录，才能分别累计；日期相同、部分重叠或缺失而不能区分时保留全部记录、标记歧义，不重复求和。

可选日期、名称或说明格式错误会返回 null 和记录级 `issues`，不删除有效金额。缺失金额、报告期、方案进度也明确记录，不能当作零或静默漏算。无效公司身份的行不纳入该股票，响应标记不完整；无法确定归属财年的记录也阻止生成参考值。非空送转比例格式错误保留现金金额，但阻止直接目标价计算。

## 应用计算口径

口径：**按数据源已实施分红汇总**。

年度合计只累计 `progress` 精确等于 `实施分配` 的记录。这是读取来源状态的明确筛选，不是推断状态；其他字符串原样返回但不计入已实施金额。

- 财年从报告期提取，不按除息日或公告年份归属。
- 没有已实施记录时 `implementedTotal=null`；明确的已实施零金额记录才可能得到 `"0"`。
- 已实施金额缺失、进度缺失而无法分类、记录歧义或分页不完整时，相关合计为 null。
- 缺少派息日、可选公告日期异常不会阻止有效现金合计。
- 已知送转行为保留原始现金合计，但不用于直接计算当前股份口径目标价；不自动复权。

参考财年由服务端按上海日期确定为上一年，不向更早年份查找。`referenceDividend` 始终返回该 `fiscalYear`，可用时返回 `cashPerShare`，不可用时金额为 null 并返回 `issues`。要求抓取及关键校验完整、已实施金额可计算、记录无歧义；该年度存在 `12-31` 报告期的实施记录。该年度及之后已实施的送转行为或送转字段异常，也会阻止当前每股口径的估值。

上述要求是应用的保守计算规则，不是来源的全年完整状态，也不表示所有款项已到账。年末实施记录不被解释为全年完整证明。非“实施分配”的非空进度原样保留，不猜测其含义；不计入已实施合计，也不因其存在而阻塞年度参考或同比。歧义检查只针对计入合计的已实施记录，避免将其他进度的记录当成重复支付。不存在该财年记录时，返回 `MISSING_REFERENCE_YEAR`，不补零。

`coverage.completeFetch` 只表示分页数量和关键记录校验通过。年度合计及可比性问题查看 `annualSummaries[].calculationIssues`，首页参考不可用原因查看 `referenceDividend.issues`。不输出财务意义上的 `complete=true`。

`shared/money.ts` 使用 BigInt 定点计算，最大 8 位小数；超出支持精度明确拒绝，不静默四舍五入。`calculateMetrics` 的期望股息率输入为百分数（如 `"5.5"`）；输出股息率和跌幅为小数比例。目标价格向下取到分，是否达到条件使用精确比较，未知基础数据返回 null。

## 请求与缓存

- 搜索缓存 5 分钟；精确公司身份缓存 24 小时；腾讯按规范化的市场＋代码集合缓存 60 秒；分红按市场＋代码缓存 1 小时。各自独立，不缓存失败结果。
- 单次行情请求最多并行解析 5 个公司身份，身份解析总预算 8 秒，再批量查询行情；按调用者原顺序返回。
- 搜索来源请求预算 5 秒；行情来源请求预算 5 秒；分红单次预算 10 秒，整个分页过程 20 秒，不自动重试。
- 东方财富首个分红请求返回 `success=false, code=9201, result=null` 时按来源明确的空记录处理（实测样本 `688981.SH`），不根据中文错误描述匹配。其他错误不当作空记录，后续分页返回空结果仍视为不完整。
- 东方财富每页 100 条，最多 20 页，核对总数及分页变化。中途失败时保留已取得明细，但不继续生成参考值。
- 固定来源 URL，不接受客户端传入抓取地址。请求使用 `redirect: manual` 并拒绝非成功响应。
- 缓存只保存完整、校验通过的来源响应；缓存不可用时仍尝试请求来源。缓存是按节点、可失效的优化，没有持久化或失败时的静态数据兜底。
- 前端同一资源刷新期间保留本页最近一次成功响应，失败后继续显示并提示“更新失败”，数据时间保留在原有数值提示与详情中；首次失败没有历史响应时保持不可用。请求地址改变时清除旧资源，不在公司之间复用数据。成功响应即替换旧响应，即使新结果明确没有可用分红，也不会用旧金额补位。行情批量响应中单家公司失败时，可保留该行本页上次有效行情，并提示“更新失败”，行情时间保留在价格提示中。
- 行情与分红各自独立更新、各自标记失败；估值可能使用最新成功行情与最近一次成功的分红数据，时间见对应字段提示。首页刷新期间保持当前行序，全部公司本轮请求结束后统一更新股息率排序。切换详情 tab 可复用本页已加载结果，显式刷新会重新请求。
- 首页打开时及手动刷新获取数据，不定时轮询；手动刷新仍遵守服务器缓存时间。浏览器最多同时发送 4 个分红请求，排队期间取消的请求不发送；30 秒超时从实际请求开始计算。
- 公司搜索仅在弹窗输入非空关键词时触发，防抖 250 毫秒，中文组词期间暂停；取消旧请求并隔离不同查询的结果。首页刷新不触发搜索。
- 最多关注 50 家公司；添加只依赖有效搜索身份，不依赖行情或分红成功。自选独立保存到本地，失败不删除关注；已关注列表可在搜索不可用时移除。

除上述同一资源刷新保留外，其他替代显示涉及身份与设置：公司名称可使用同代码的行情名称、添加时的搜索名称或分红接口公司名称，均不可用时显示代码；详情也可使用同公司的年度统计名称。无效的期望股息率输入不会覆盖已保存值，页面明确提示当前使用的值；本地设置读取失败时使用默认设置并显示错误，不静默覆盖原记录。缺失金额和日期显示“—”或“未提供”，不补造数值或日期。部分抓取成功时，只展示实际取得的有效记录并提示不完整；逐次明细不完整时不计算每股年度合计，年度统计中独立有效的行仍可显示。

## 分红详情页展示

- 路由 `/dividends/:code`；复用同一分红接口。首页小图、每股分红图表和当年分组统一使用服务端返回的 `referenceDividend.fiscalYear` 作为最后已结束财年，不读取设备当前日期；即使参考金额为 null，也保留该固定年度。近 5／10 年固定为截至上一财年的自然年份窗口，不受来源最新记录影响；“全部”从来源最早已结束年份展示至上一财年。中间与末尾缺年均保持未知，不生成分红明细。未结束财年与无法归属财年的记录不受历史范围筛选而丢失。
- 年度大柱读取 `implementedTotal`；只有合计可用时才绘制对应的单次实施记录小柱，两者共用金额刻度及零基线。前端不另行累加预案或未知进度。
- 年度同比要求相邻两年合计可用、均无计算问题，且上年金额大于零，使用定点运算并四舍五入到两位小数。不能比较时不显示同比。已知送转问题不抹去原始金额，但阻止同比和目标价参考。
- 按 `exDate` 升序排列年度内记录，缺失值置后。显示“报告期”和来源原始进度，不生成中期、末期、特别分红或到账状态。
- 图表桌面总高 400px、绘图区 324px；650px 及以下屏幕总高 320px、绘图区 244px。图内顶部留白 24px，底部预留 52px 给年份标签。SVG 使用实测容器宽高，切换范围时不重置尺寸。年度柱最大宽 84px，单次柱最大宽 24px、间距最大 4px，小柱整体居中，窄屏随可用空间缩小。
- 年份范围与切换按钮同组，窄屏省略范围文字并优先保持标题与按钮同排。纵轴采用易读的等距步长，从零开始并保留顶部空间；刻度取整只影响图形比例，不改变分红金额。左侧留白按实际刻度文字宽度测量。
- 金额标签使用主题中的 15px、650 字重，按实际 SVG 文字尺寸计算显示间隔并优先保留最新年度，命中区域覆盖同一文字边界。详情金额至少显示三位小数，更多有效小数完整保留，不使用浮点转换截断金额。
- 图例为可切换按钮：年度与单次层级互斥，重复点击取消；仅改变视觉强调，不改变柱体几何、刻度或统计。选择在本页切换范围、刷新数据时保留；鼠标悬停与键盘聚焦可临时覆盖，结束后恢复。手机可通过图例选择层级，再点击柱子查看明细。
- 悬停交互沿用原型：命中区限于实际柱体、金额和年份标签，空白区清除临时悬停并恢复图例选择；tooltip 锚定命中元素，不跟随鼠标移动。淡化过渡为 120ms，透明度不改变命中区；点击、失焦、滚动、缩放窗口或 Esc 清除提示。
- `recordId` 仅用于当前响应内交互，不作为可跨刷新持久访问的记录 URL。单次记录弹窗保留打开时的记录与获取时间。
- `sourceUrl` 是数据接口地址，不作为公告原文链接。派息日和公告原文暂不展示；额外说明收于页脚“数据说明”。

## 年度分红比例

`GET /api/companies/:code/allocations` 返回 `{ data: AllocationHistory, meta }`。`data.lastEndedYear` 是服务端响应时按上海日期确定的上一年，图表直接使用这个日历基准；该字段在读取来源缓存之后计算，不以来源抓取时间或设备时钟替代。使用相同的 A 股身份解析与错误响应规则，独立于分红明细加载；前端首次选择“分红比例”时请求，并在本次公司详情访问期间保留请求状态；同页切换不重复请求，手动刷新重新获取。离开详情页后释放，不写入浏览器存储，不增加首页逐公司请求。加载、空结果和首次失败共用图表与比例区域的布局，避免加载完成前后高度跳变。

来源为东方财富 `RPT_F10_DIVIDEND_HISTOGRAM`，地址 `https://datacenter.eastmoney.com/securities/api/data/v1/get`，按完整 `SECUCODE` 过滤。字段含义依据东方财富 [F10 分红融资页面](https://emweb.securities.eastmoney.com/pc_hsf10/pages/index.html?type=web&code=SH601939#/fhrz)的年度统计实现，并通过实际响应核对。

| 年度字段       | 来源              | 口径                                           |
| -------------- | ----------------- | ---------------------------------------------- |
| `fiscalYear`   | `REPORT_DATE`     | 仅接受 `12-31` 年度报告期                      |
| `netProfit`    | `PARENTNETPROFIT` | 归母净利润，人民币元，可为负                   |
| `cashDividend` | `DIVIDEND_IMPLE`  | 同财年已实施现金分红总额，人民币元，可明确为零 |
| `issues`       | 字段校验          | 缺失或无效字段保持 null                        |

`DIVIDEND_PAY_IMPLE` 是百分比，不是金额；`DIVIDEND_PLAN` 和 `DIVIDEND_PAY_PLAN` 含预案，本接口不使用。金额取自同一条公司年度统计，不从每股分红和当前股本反推，不解析方案文字。公司年度总额与 A 股逐次明细分别保留各自口径，不用两者互相补造缺失数据。

前端规则：
